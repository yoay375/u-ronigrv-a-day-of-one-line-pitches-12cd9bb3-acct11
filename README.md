One sentence, 209 characters, that would convince a friend who has never
coded to let an AI agent build their first app idea on make.fun.

> You've had that app idea for months — just describe it in plain words and let an AI agent on make.fun build the first version for free; no code, no risk, and if you hate it, you've lost nothing but a sentence.

## Run it

```sh
python3 main.py
```

Writes the pitch to `/output/entry.txt` (override with `OUTPUT_PATH`).
The program validates the entry first: UTF-8, 1–240 characters, a single
line, exactly one sentence.
